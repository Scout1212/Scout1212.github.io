# Robert Zamora · Now Showing

My project portfolio, styled as a cinema program. Live at **https://scout1212.github.io**.

Built with [Astro](https://astro.build) and [Claude](https://claude.com/claude-code) (AI). Every push to `main` deploys automatically through GitHub Actions.

```bash
npm install
npm run dev     # preview at http://localhost:4321
npm run build   # build to dist/
```

Projects live in `src/content/features/`, one file per project.
