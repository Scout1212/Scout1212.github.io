## Synopsis

No Unity, no game library. Just Java and a blank window. I wrote the game loop, drawing, collision, sound, and room system myself, which is a lot of what a game engine normally does for you.

Each run is a gauntlet. Clear a room and the doors unlock; walk through a hallway and the next room is waiting with more enemies than the last. Between fights you can step into Bongo's shop and spend the chips you've collected, if you're willing to gamble. Your score is simply how many rooms you survive.

## Behind the scenes

The whole game runs on one loop, sixty times a second, in a fixed order: read the keyboard, move the player, let every enemy act, check every collision, update the room, and redraw. Each kind of thing in the world is its own class (the player, enemies, both kinds of projectiles, the shopkeeper, doors, items, and traps), so adding a new enemy or item didn't mean touching the rest of the game.

Some of the systems I built:

- **Rising difficulty**: every room you clear spawns more enemies, and each one gets about 10% more health, speed, and fire rate than the last batch.
- **Doors that lock** until the room is empty, so you can't run past a fight.
- **Stamina**: sprinting drains a bar; walking lets it refill.
- **A shop of gambles**: eleven items, each a buff or a curse. Some are hidden behind a “?”, so that “mystery item” might turn out to be *Lead Boots* or *Bongo's Crippled Scope*.
- **Sound**: background music that switches with the room, plus effects for footsteps, doors, purchases, and portals.

## Enemies with nerves

The enemy AI is small but has personality. Enemies close in until they're within range, then hold their distance and fire. But a few spawn scared, and *any* enemy that drops below 3 health panics, turns around, and runs for the walls instead of shooting:

```java
// non scared go to player and scared enemies will run away
if (hp < 3)
    scared = true;
if (scared) {
    if (x > this.x) accelLeft(leftBound);   // player is to the right → flee left
    else if (x < this.x) accelRight(rightBound);
    ...
} else if (distance(this.x, this.y, x, y) > diam) {
    if (x < this.x) accelLeft(leftBound);   // chase until within range
    else if (x > this.x) accelRight(rightBound);
    ...
}
```

It's only a few lines, but it means a fight never ends the same way twice: the last enemy in a room is often the one sprinting away from you.

## The structure

```text
Engine/
├── LearningGraphics      game loop, rendering, rooms, collisions
├── Parents/
│   ├── Player/           Player · PlayerProjectile
│   ├── Enemy/            Enemy · EnemyProjectile
│   └── Npc/              Npc (Bongo, the shopkeeper)
└── Map/
    ├── Door/             room transitions
    ├── Item/             shop items and their stat effects
    └── Trap/             spike traps
```
